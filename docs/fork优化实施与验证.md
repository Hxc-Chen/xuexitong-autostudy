# fork 优点移植与验证

日期：2026-11-17。此轮优化已归入当前维护分支 v1.0.20；本地版本更新不代表远端发布。

项目基于 [ZhangYHhhhhhh 的 fork](https://github.com/ZhangYHhhhhhh/xuexitong-autostudy) 继续维护，原项目为 [DaRin1403](https://github.com/DaRin1403/xuexitong-autostudy)。本轮参考目录 xuexitong-autostudy-folk 来自 [cq-eng 的 fork](https://github.com/cq-eng/xuexitong-autostudy)，感谢其字形指纹、严格解析和页面适配实现提供的参考。

## 已实施

1. 普通单选、多选和判断答案整段验证。拒绝 Because 等解释、含矛盾结论的多行、含糊判断；允许明确答案前缀、简单 Markdown 包裹和分隔多选。验证实际选项范围，无效输出走原有一次恢复。
2. 题型依次参考本题显式字段、qid/qtype、标题开头的独立标签与控件结构。正文出现“判断题”等词不会改变题型；未知、混杂或无法归属的结构按待检查处理。
3. 支持 ARIA、Element 风格和 option/answer 组件；按根节点去重、排除显式隐藏模板、按唯一精确文本对应选项。原生 checked 或明确 aria-checked 状态优先，普通焦点/active 样式不作为新组件成功依据。
4. 内置 20,902 条本地字形指纹，保留原有字体来源发现、Unicode 筛选、CSSOM/外链/动态 FontFace 支持。二进制可读时先查本地字形；只把未命中字交给视觉模型。全部识别成功后逐字符一次性替换，保留控件和事件。
5. 设置增加“本地字形识别优先”，默认开启。遇到识别不符可关闭并刷新，以恢复仅用视觉模型的识字路径。关闭不改变答题模型配置。
6. 字体诊断新增 localStatus、tableVersion、localHits、visionRequested、visionHits、unresolved；题目结构诊断新增本题编辑器计数、可读性及内容长度，不导出正文或其他题的实例。
7. vendor 固定资源及 SHA-256，构建不联网。组件隔离在脚本闭包内，首次需要时初始化；不向页面注入 Typr/md5 全局变量。发布白名单包含资源、构建工具、来源说明和新增测试。

主版阅读/连线题、暂存继续、待检查汇总、模型截断拒绝/有限恢复及提交复检继续保留。

## 验证方法

    npm test
    npm run check
    npm run build:fonts

测试共 120 项：原有 92 项 + 新增 28 项。新增样例覆盖普通答案格式/范围/恢复、题型缺失/正文干扰/子题隔离、ARIA 与 Element 控件、重复/隐藏选项、假选中与残留多选、本题编辑器诊断，以及本地/视觉组合识字。

字体测试还使用自行构造的 cmap/glyf 字体，通过真实 Typr 路径解析、MD5 和注入的合成映射，验证补充平面字符及非零 byteOffset 的读取。测试使用的合成字形与注入映射不证明生产指纹表对真实字体的覆盖率。

tools/compare-fork.cjs 已调整为比较优化后的主版与原本地 fork，8 组差异检查继续可运行。原始对比报告与 JSON 保留为修改前的历史证据，不覆盖旧结果。

## 使用与回退

- 将当前学习通刷课助手.user.js 更新到用户脚本管理器，并刷新课程页面后才会加载本轮修改。当前版本为 1.0.20；远端源码未上传前可手动更新，更新后核对面板版本。
- 第一次试用可关闭自动提交，核对提取、填写及字形；查看导出中的诊断计数。真实页面验证尚未执行。
- 本地识字不符时：设置中关闭“本地字形识别优先”并刷新；已写回的 DOM 不会因关开关自动还原。
- 指纹表采用原资源的 MD5 后 8 位索引，字形查表命中不是正确率保证；未知或失败时仍依赖配置的视觉模型。

## 依赖与发布

来源详情见 [vendor/NOTICE.md](../vendor/NOTICE.md)。资源锁定来自已有本地 fork，不自动跟随上游 main，也未在线更新第三方组件。原快照没有附独立完整版权文件，保留其已有声明并明确记录来源边界。

用户运行时只需要单个 .user.js；vendor 与工具用于重建和验证。依赖内置会增大脚本体积，未进行真实浏览器耗时或模型费用节省测量。

打包使用现有明确白名单，可分别生成个人 fork 与上游 PR 包；此流程仅生成本地文件，不提交、推送或发布代码。
