# v1.0.20 发布与验证

当前维护仓库：[Hxc-Chen/xuexitong-autostudy](https://github.com/Hxc-Chen/xuexitong-autostudy)。本项目基于 [ZhangYHhhhhhh/xuexitong-autostudy](https://github.com/ZhangYHhhhhhh/xuexitong-autostudy) 的 fork 版本，参考 fork 为 [cq-eng/xuexitong-autostudy](https://github.com/cq-eng/xuexitong-autostudy)，原项目为 [DaRin1403/xuexitong-autostudy](https://github.com/DaRin1403/xuexitong-autostudy)。

**版本：1.0.20；日期：2026-11-17。** 本版收录答案解析、题型/控件适配和本地字形识别优化，并统一来源与致谢。生成本地包不代表远端仓库或 Release 已更新。

## 发布范围

源码包通过 tools/package-release.py 的明确文件白名单生成，包含：

- 用户脚本、README、CHANGELOG、LICENSE 和版本元数据。
- npm 清单、锁文件、公开模块文档与贡献说明。
- 120 项离线测试及合成样例。
- vendor 字体资源、散列锁、来源说明与离线构建工具。
- 诊断和打包工具。

不包含密钥、真实题目、个人问题记录、运行日志、node_modules、缓存、旧包及完整参考项目目录。字形依赖块为选择性纳入的构建资源，不等于打入完整 cq-eng 仓库。

## 验证命令

使用 Node.js 20+、npm 和 Python 3.10+：

    npm ci --ignore-scripts
    npm test
    npm run check

修改字体资源后，先运行 npm run build:fonts。构建只读锁定的本地文件，不下载远端组件；npm run check 验证生成块与锁定资源一致。普通测试不访问学习通、提交测验或调用真实模型。

## 生成两种包

个人 fork 包：

    python tools/package-release.py --target fork

- dist/xuexitong-autostudy-v1.0.20-github.zip
- dist/xuexitong-autostudy-v1.0.20-MANIFEST.json
- dist/xuexitong-autostudy-v1.0.20-SHA256.txt

上游 PR 包：

    python tools/package-release.py --target upstream

- dist/xuexitong-autostudy-v1.0.20-upstream-pr-github.zip
- dist/xuexitong-autostudy-v1.0.20-upstream-pr-MANIFEST.json
- dist/xuexitong-autostudy-v1.0.20-upstream-pr-SHA256.txt

两者业务逻辑与版本相同。个人包使用 Hxc-Chen 更新通道，上游 PR 包使用 DaRin1403 通道；两个包均保留 ZhangYHhhhhhh 和 cq-eng 来源与致谢。上游地址在合并前可能仍提供旧代码。

包内 RELEASE-MANIFEST.json 逐文件记录大小和 SHA-256，并记录来源与目标；打包同时检查版本一致性、Markdown 包内链接、常见凭据模式及压缩后内容。模式扫描不能替代人工审阅。

解压后应从包内项目目录执行 npm ci --ignore-scripts、npm test、npm run check。运行用户脚本只需单个 .user.js；开发与重建才需要其余资源。

## 上传与更新

1. 按目标选择个人包或上游 PR 包，审阅文件清单。
2. 解压，将包内项目目录的内容放到目标仓库根目录；不要仅上传 ZIP 代替源码。
3. 提交前确认原作者署名、来源致谢、更新地址和 v1.0.20 元数据一致。
4. 源码上传后核对安装地址；如需创建 Release，可使用 v1.0.20 标签及对应 ZIP、SHA256。
5. 用户通过脚本管理器更新后刷新课程页面，检查日志版本。

详细上游流程见 [上游PR说明.md](上游PR说明.md)，审阅正文见 [PR正文.md](PR正文.md)。本地工具不执行提交、推送或远程发布。

## 后续版本

同时更新脚本 @version、scriptVersion()、version.json 的 v 字段、package.json、package-lock.json 顶层及根项目版本，再维护 README、CHANGELOG 和发布说明。version.json 中 repository 表示当前包目标，upstream 表示原项目，forkedFrom 表示本项目基础 fork，referenceFork 表示参考版本来源。

历史对比报告、旧实测 JSON 与参考项目保留其原版本号，不能为统一当前版本而篡改快照。
